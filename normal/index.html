Project Details

Fantasy Warrior

Character Design High Poly PBR Textures

Project Details

This fantasy warrior character was created for a AAA game project. The model features high-resolution sculpted details, fully rigged for animation, with 4K PBR textures for realistic material representation.

Technical Specifications

  • Polycount: 125,000 tris
  • Textures: 4K PBR (Albedo, Normal, Roughness, Metalness, AO)
  • Software Used: ZBrush, Maya, Substance Painter, Marmoset Toolbag
  • Timeframe: 3 weeks

Challenges & Solutions

The main challenge was creating intricate armor details while maintaining good topology for animation. I solved this by using a combination of high-poly sculpting in ZBrush and manual retopology in Maya to ensure clean edge flow in deformation areas.
